# Établi 3D — notes pour Claude

- Application pour des élèves de collège : tous les textes visibles sont en français, ton simple et direct.
- Le code source est dans `src/`. Ne modifiez jamais `dist/` à la main : lancez `python3 build.py`.
- Les fichiers `src/*.js` partagent une seule portée (concaténés dans l'ordre de `JS_ORDER` dans `build.py`). Pas d'`import`/`export` entre eux ; seuls three.js et three-bvh-csg sont importés, via l'import map.
- Repère : Z vers le haut, unités en millimètres, chaque pièce a sa base à z = 0 dans son repère local.
- Avant de pousser : `npm test` (nécessite `npm install` et Playwright) doit afficher « TOUT EST OK ».
- `dist/artifact.html` est la même page sans `<html>`/`<head>`, pour la version publiée sur claude.ai.
- Les exemples de démonstration sont dans `src/examples.js` (objet `SAMPLES`) : chaque exemple a une fiche « À observer / À essayer » ; les positions sont en coordonnées monde.
- Niveaux : `<html data-level="1|2|3">`. Marquez un élément `data-min="2"` ou `data-min="3"` pour le réserver à un niveau, `data-max="2"` pour le masquer au-dessus ; en JS, testez `lv(n)`. Les formes ont leur niveau dans `KIND_LVL`, chaque exemple dans `level`.
- Ateliers : `<html data-ws="model|check|mech|struct">` ; un élément `data-ws="model mech"` n'apparaît que dans ces ateliers. Changez d'atelier avec `setWs(k)`, testez `ws`. Pas de bandeau : la navigation est dans `#flow` (barre du haut), rendue par `updateSteps()`.
- Panneaux flottants : listés dans `FLOATS` (`src/panels.js`) ; position et réduction dans `LAYOUT` (localStorage), réinitialisées par `resetLayout()`. La bulle (`#bubble`) se déplace par son en-tête (`LAYOUT.bubble`) ; transparence des panneaux : `prefs.glass` → `<html data-glass>`. La Mécanique exige `mechReady()` (toutes les pièces validées).
- Validation : `p.valid` (statut, triangles, proxy) et `p.locs` (repères, en coordonnées locales de la pièce). `vState(p)` renvoie `stale` si la géométrie a changé depuis la validation.
- Structures : `state.struct` (treillis + maillage), unités mm / N / MPa, plan vertical (x, y) affiché en (X, Z) dans la vue 3D.
- Le push sur `main` déploie automatiquement sur GitHub Pages.
- Déformée « auto » : l'échelle est figée par modèle (`ST.ampRef`, remise à zéro par `resetAmpRef()` au chargement d'un exemple ou au changement de module/portée) pour qu'une force plus grande se voie ; plafond à 30 % de la portée.
- Disposition : barre de création en haut (`#rack` : esquisse, volumes, puis les outils `#tools`), panneau de réglages (`#insp`) à gauche par défaut (`LAYOUT.inspLeft ?? true`, classe `insp-right` sinon), arborescence à gauche. Ces panneaux sont semi-transparents : sur grand écran, les canevas 3D et 2D s'étendent dessous (`OVR.t` / `OVR.l` / `OVR.r` mesurés sur la mise en page, variables CSS `--ovr-*`, `updateOverlay()`). Pour placer quelque chose sur la vue, utilisez `toStage(v)` (monde → coordonnées de `#stage`) et `evStage(ev)`, pas le rectangle du canevas.
- Structures 3D : mêmes symboles qu'en 2D (flèches de charge, appuis, réactions, forme au repos, flèche max) ; les textes sont des étiquettes HTML dans `#st3d`, placées chaque image par `positionStruct3DLabels()`.
- Bulle : `#bubLink` relie la bulle à l'élément ciblé (`bubbleAnchor()`), mis à jour chaque image.
- Étiquettes de liaison : groupe déplaçable et transparent `#jlGroup`, disposition `prefs.jl` (orbite par défaut, libre, ligne, colonne, carre, rect, cercle), réduction automatique `data-sz` (full → compact → mini). Toutes les dispositions sauf « libre » sont calculées chaque image par `freeJointLabels()` / `placeJointLabels()` autour de la boîte écran des pièces en mouvement (`systemScreenBox()`) : ovale, cercle, ligne au-dessus, colonne ou grille du côté le plus libre.
- Survol (`src/hover.js`) : liseré (`hull`, normales lissées), nom (`#hovName`), pièce grisée ; aucun choix de mode au survol. Clic répété = pièce suivante sous le curseur (`pickAll`). Maj + glisser dans le vide = cadre de sélection.
- Poignées de sélection à la Tinkercad (`src/gizmo.js`, `#tg`, `tgTick()` chaque image) : coins / milieux des côtés / haut = taille (cotes via `SCALE_MAP` / `scaleParams()`, côté opposé fixe), cône = soulever, flèches courbes = rotation (rapporteur `TG.ring`, pas de 15°, Maj : 1°), cotes cliquables (`tgEditDim`). Les TransformControls (`tc`) ne sont plus affichés. Glisser la pièce = plan horizontal.
- Modifier l'intérieur d'un groupe : `enterGroupEdit(id)` remet les enfants dans la scène (`p.inGroup`, `state.edit`, le reste estompé et non cliquable via `editable()`), `finishGroupEdit()` reconstruit le groupe (même id, perçages recalculés). Sortie automatique en changeant d'atelier, en enregistrant ou en exportant.
- Préférence du clic gauche dans le vide : `prefs.lmb` (select / orbit / pan), réglée par le menu du clic droit (`openCtxMenu`) ou le bouton souris de `#views` (`applyLmb()`).
- Esquisses : contour extérieur dans le sens trigonométrique et trous dans le sens horaire (sinon les parois des trous sont retournées).
- Cube de vue (`src/viewcube.js`, canevas `#vcube` dans `#views`) : clic face / arête / coin → `vcGo(dir)`, glisser → `vcOrbit`, boutons autour (`data-view` iso / fit / sel, `#lmbBtn`).
- Magnétisme en glissant une pièce (`smartSnap` dans scene.js) : bords et centres alignés ou en contact avec les autres pièces, à quelques pixels près ; guides `SNAPSEG` dessinés par `tgTick`. Alt désactive.
- Cadre de sélection : une pièce est prise dès qu'une partie est dans le cadre (`partInRect`).
