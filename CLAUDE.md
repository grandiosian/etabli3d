# Établi 3D — notes pour Claude

- Application pour des élèves de collège : tous les textes visibles sont en français, ton simple et direct.
- Le code source est dans `src/`. Ne modifiez jamais `dist/` à la main : lancez `python3 build.py`.
- Les fichiers `src/*.js` partagent une seule portée (concaténés dans l'ordre de `JS_ORDER` dans `build.py`). Pas d'`import`/`export` entre eux ; seuls three.js et three-bvh-csg sont importés, via l'import map.
- Repère : Z vers le haut, unités en millimètres, chaque pièce a sa base à z = 0 dans son repère local.
- Avant de pousser : `npm test` (nécessite `npm install` et Playwright) doit afficher « TOUT EST OK ».
- `dist/artifact.html` est la même page sans `<html>`/`<head>`, pour la version publiée sur claude.ai.
- Les exemples de démonstration sont dans `src/examples.js` (objet `SAMPLES`) : chaque exemple a une fiche « À observer / À essayer » ; les positions sont en coordonnées monde.
- Guide (`src/guide.js`, élément `#demo`, bouton `#bGuide`) : panneau flottant à gauche de la vue, à droite de l'arborescence (au-dessus de l'éditeur pendant une esquisse, `placeDemo()`). Onglets Exemple (fiche de `state.note`, « À essayer » en pas à pas), Tutos (`TUTOS` : étapes avec `ok()` vérifiée deux fois par seconde, une étape faite le reste) et Mon TP (`state.tp = {title, tasks:[{t, done}]}`, écrit par le professeur, enregistré avec le projet). État : `GUIDE`, ouverture `demoClosed` / `demoOpen`.
- Niveaux : `<html data-level="1|2|3">`. Marquez un élément `data-min="2"` ou `data-min="3"` pour le réserver à un niveau, `data-max="2"` pour le masquer au-dessus ; en JS, testez `lv(n)`. Les formes ont leur niveau dans `KIND_LVL`, chaque exemple dans `level`.
- Ateliers : `<html data-ws="model|check|mech|struct">` ; un élément `data-ws="model mech"` n'apparaît que dans ces ateliers. Changez d'atelier avec `setWs(k)`, testez `ws`. Pas de bandeau : la navigation est dans `#flow` (barre du haut), rendue par `updateSteps()`.
- Panneaux flottants : listés dans `FLOATS` (`src/panels.js`) ; position et réduction dans `LAYOUT` (localStorage), réinitialisées par `resetLayout()`. La bulle (`#bubble`) se déplace par son en-tête (`LAYOUT.bubble`) ; transparence des panneaux : `prefs.glass` → `<html data-glass>`. La Mécanique exige `mechReady()` (toutes les pièces validées).
- Validation : `p.valid` (statut, triangles, proxy) et `p.locs` (repères, en coordonnées locales de la pièce). `vState(p)` renvoie `stale` si la géométrie a changé depuis la validation.
- Structures : `state.struct` (treillis + maillage), unités mm / N / MPa, plan vertical (x, y) affiché en (X, Z) dans la vue 3D.
- Le push sur `main` déploie automatiquement sur GitHub Pages.
- Version publiée sur claude.ai : après chaque push, republier `dist/artifact.html` sur l'artefact existant https://claude.ai/artifact/XoZ1sPmBrX1jkPcmeEoHVf (passer cette adresse en `url` pour garder le même lien ; ne pas créer un nouvel artefact).
- Déformée « auto » : l'échelle est figée par modèle (`ST.ampRef`, remise à zéro par `resetAmpRef()` au chargement d'un exemple ou au changement de module/portée) pour qu'une force plus grande se voie ; plafond à 30 % de la portée.
- Disposition : barre de création en haut (`#rack` : onglets `[data-rtab]` Volumes / Simulation mécanique (roues dentées, crémaillère, niveau 3) qui montrent `#rackBasic` ou `#rackMeca` (`setRackTab()`, mémorisé dans `LAYOUT.rackTab`), boutons d'esquisse `[data-sktool]` à droite, enfoncés seulement pendant le choix du plan), barre d'édition juste dessous (`#toolbar` : résumé de la sélection `#edSel`, gros boutons rangés par famille « Convertir en » Solide / Perçage, « Assembler » Grouper / Dégrouper, « Pièce » Dupliquer / Poser / Supprimer, actifs selon la sélection dans `updateToolButtons()`), panneau des propriétés (`#insp`) flottant sous le cube de vue à droite (`placeInsp()`, déplaçable par son en-tête → `LAYOUT.insp`, réductible, bouton ⟲ pour le remettre ; `rightReserve()` décale la caméra pour ne pas cacher la scène), arborescence à gauche (colonne `tree` de la grille), le Guide juste à sa droite sur la vue. En Modéliser, le panneau s'intitule « Propriétés » (`updateSteps()`) et invite à cliquer un objet quand rien n'est choisi ; les rappels des gestes sont dans le Guide (onglet Tutos). Barres et arborescence sont semi-transparentes : sur grand écran, les canevas 3D et 2D s'étendent dessous (`OVR.t` / `OVR.l` / `OVR.r` mesurés sur la mise en page, variables CSS `--ovr-*`, `updateOverlay()`). Pour placer quelque chose sur la vue, utilisez `toStage(v)` (monde → coordonnées de `#stage`) et `evStage(ev)`, pas le rectangle du canevas.
- Structures 3D : mêmes symboles qu'en 2D (flèches de charge, appuis, réactions, forme au repos, flèche max) ; les textes sont des étiquettes HTML dans `#st3d`, placées chaque image par `positionStruct3DLabels()`.
- Bulle : `#bubLink` relie la bulle à l'élément ciblé (`bubbleAnchor()`), mis à jour chaque image.
- Étiquettes de liaison : groupe déplaçable et transparent `#jlGroup`, disposition `prefs.jl` (orbite par défaut, libre, ligne, colonne, carre, rect, cercle), réduction automatique `data-sz` (full → compact → mini). Toutes les dispositions sauf « libre » sont calculées chaque image par `freeJointLabels()` / `placeJointLabels()` autour de la boîte écran des pièces en mouvement (`systemScreenBox()`) : ovale, cercle, ligne au-dessus, colonne ou grille du côté le plus libre.
- Survol (`src/hover.js`) : liseré (`hull`, normales lissées), nom (`#hovName`), pièce grisée ; aucun choix de mode au survol. Clic répété = pièce suivante sous le curseur (`pickAll`). Maj + glisser dans le vide = cadre de sélection.
- Poignées de sélection à la Tinkercad (`src/gizmo.js`, `#tg`, `tgTick()` chaque image) : coins / milieux des côtés / haut = taille (cotes via `SCALE_MAP` / `scaleParams()`, côté opposé fixe ; un groupe s'étire aussi : aperçu par l'échelle du maillage, puis `scaleParams` reporte l'étirement sur ses pièces au relâchement), cône = soulever, arcs fléchés dans le plan de chaque rotation (`tgArc`, pastille au milieu) = rotation (rapporteur `TG.ring` affiché au survol (`TG.hover`) et pendant la rotation, graduations noires liserées de blanc de 5° / 15° / 45° avec étiquettes `TG.marks`, liseré épais sur la graduation sous le pointeur ou attrapée (`tgHi`, `tgHoverTick`) ; le 0° du rapporteur est sous la poignée (`TG.gripW`) ou le point attrapé, pour que les crans vus sous le pointeur soient ceux qui aimantent ; aimantation `tgSnapAngle()` à 6 / 10 / 16 px des petites / moyennes / grandes graduations (`TG_SNAP`), sinon au degré ; Maj : libre ; pendant une rotation, les autres poignées, le cadre et les cotes sont masqués (`#tg.turning`)), cotes cliquables (`tgEditDim`). Les esquisses s'étirent aussi en X / Y (`scaleSketch` : points, cercles, poignées de Bézier et valeurs des cotes). Les TransformControls (`tc`) ne sont plus affichés. Glisser la pièce = plan horizontal.
- Modifier l'intérieur d'un groupe (« mode édition du groupe ») : `enterGroupEdit(id)` remet les enfants dans la scène (`p.inGroup`, `state.edit`) et isole le groupe : le reste est caché dans la vue (`sync()`) et dans l'arborescence, non cliquable via `editable()`, la vue cadre le groupe ; `finishGroupEdit()` reconstruit le groupe (même id, perçages recalculés). Sortie automatique en changeant d'atelier, en enregistrant ou en exportant.
- Navigation 3D : Alt + clic gauche = tourner la vue, Espace + clic gauche = décaler la vue, même sur une pièce (`NAV` dans hover.js change `orbit.mouseButtons.LEFT`, `beginPointer` laisse faire OrbitControls) ; inactif pendant une esquisse (elle a son propre Espace).
- Préférence du clic gauche dans le vide : `prefs.lmb` (select / orbit / pan), réglée par le menu du clic droit (`openCtxMenu`) ou le bouton souris de `#views` (`applyLmb()`).
- Esquisses : contour extérieur dans le sens trigonométrique et trous dans le sens horaire (sinon les parois des trous sont retournées).
- Cube de vue (`src/viewcube.js`, canevas `#vcube` dans `#views`) : clic face / arête / coin → `vcGo(dir)`, glisser → `vcOrbit`, boutons autour (`data-view` iso / fit / sel, `#lmbBtn`).
- Magnétisme en glissant une pièce (`smartSnap` dans scene.js) : bords et centres alignés ou en contact avec les autres pièces, à quelques pixels près ; guides `SNAPSEG` dessinés par `tgTick`. Alt désactive.
- Cadre de sélection : une pièce est prise dès qu'une partie est dans le cadre (`partInRect`).
- Plan d'esquisse (`src/planes.js`) : les boutons d'esquisse ouvrent `openPlanePicker(tool)` (panneau `#planePick` + trois plans cliquables dans la vue, via `pickMode`) puis `openSketch(null, {plane, tool})`. `SKPLANES` (xy dessus, xz face, yz côté) ; la pièce garde `params.plane` et reçoit `rot = planeRot(plane, mode)` à sa création (extrusion : profil sur (u, v), épaisseur selon u × v ; révolution : axe = axe vertical de l'esquisse). Les anciennes esquisses sans `plane` gardent leur comportement.
- Bézier (niveau 2) : outil plume point par point (clic = point anguleux, cliquer-glisser = point lisse symétrique, Alt = tangente cassée). Chaque point a `it` (`lin` anguleux, `auto` lisse automatique, `bez` à la main) et, pour `bez`, `tm` (`sym`, `align` = dessymétrisé, `free` = cassé) ; les poignées restent dans les courbes (`t1` au départ `a`, `t2` à l'arrivée `b`) et `bzRefresh()` recalcule celles des points `lin` / `auto`. Barre d'options `#bzOpts` pour le point en cours ou sélectionné (`bzSetInterp`, `bzSetType`). Points sans `it` : `bez` / `free` (anciens fichiers).
- Perçages : même matériau que les solides (`partMaterial()`), avec la définition `HATCH` (`setHatch`) qui ajoute des hachures obliques en coordonnées écran (toujours face caméra) sur une pièce transparente ; pas et épaisseur dans `HATCH` (× pixelRatio).
- Sélection dans l'esquisse : `SK.sel` (un élément) ou `SK.msel` (plusieurs : cadre en glissant dans le vide, Maj + clic) ; filtre `SK.filt` (points, arêtes, contraintes) réglé par `#skFilt`. Glisser un élément d'une sélection multiple déplace tous ses points. Panoramique : Espace + clic gauche (`SK.space`), clic du milieu ou droit. `skCleanup()` garde les points de la chaîne en cours (`SK.pend`, `SK.chain`).
